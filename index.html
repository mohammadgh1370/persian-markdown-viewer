پیش‌نمایش و خواننده Markdown فارسی

متن Markdown را در کادر زیر paste کنید یا فایل .md را باز کنید. جهت هر پاراگراف، لیست، جدول و عنوان جداگانه تشخیص داده می‌شود تا متن فارسی، انگلیسی و ترکیبی درست و خوانا نمایش داده شود و کد همیشه چپ‌به‌راست بماند.

ابزار آنلاین خواندن Markdown فارسی

این ابزار یک خواننده‌ی آنلاین Markdown است که برای متن‌های فارسی، انگلیسی و ترکیبی ساخته شده. محتوا را paste می‌کنید یا فایل را باز می‌کنید و همان‌جا در مرورگر، با فونت و چیدمان مناسب فارسی، به شکل صفحه‌ای خوانا نمایش داده می‌شود. برای مستندات فنی، یادداشت‌ها و متن‌های طولانی‌ای که از ویرایشگرها یا ابزارهای هوش مصنوعی کپی می‌کنید مناسب است.

امکانات ابزار

  • تشخیص جهت هر بخش: پاراگراف، عنوان، آیتم لیست، نقل‌قول و سلول جدول هرکدام جداگانه راست‌به‌چپ یا چپ‌به‌راست می‌شوند.
  • متن ترکیبی فارسی و انگلیسی: نام فایل، دستور یا اصطلاح انگلیسی وسط جمله‌ی فارسی یک واحد چپ‌به‌راست می‌ماند و علائم نگارشی جابه‌جا نمی‌شوند.
  • کد: بلوک‌های کد و کد درون‌خطی همیشه چپ‌به‌راست‌اند، رنگ‌آمیزی سینتکس دارند و توضیح فارسی داخل کد جداگانه و درست نمایش داده می‌شود.
  • Markdown استاندارد (GFM): عنوان‌ها، لیست‌های تودرتو، لیست کارها، جدول‌ها (با اسکرول افقی)، نقل‌قول، لینک و تصویر.
  • نمودار متنی: نمودارهای ساخته‌شده با کاراکترهای جعبه‌ای (┌ │ ▶) که متن فارسی دارند، مرتب و هم‌تراز نمایش داده می‌شوند.
  • فهرست مطالب: از روی عنوان‌ها ساخته می‌شود، بخش فعلی را نشان می‌دهد و قابل بستن است؛ نوار پیشرفت خواندن هم دارد.
  • تنظیمات خواندن: اندازه‌ی متن، عرض خط، فونت (وزیرمتن یا نسخ) و پوسته (خودکار، روشن، تیره، کاغذی).

نحوه استفاده

  1. متن Markdown را در کادر بالای صفحه paste کنید (با paste در کادر خالی، نمایش خودکار شروع می‌شود)، یا با دکمه‌ی «باز کردن فایل Markdown» یک فایل .md انتخاب کنید یا فایل را روی صفحه بکشید و رها کنید.
  2. اگر متن را به روش دیگری وارد کرده‌اید، روی «نمایش برای خواندن» بزنید (یا Ctrl+Enter).
  3. با فهرست مطالب بین بخش‌ها جابه‌جا شوید و از «تنظیمات خواندن» اندازه، عرض، فونت و پوسته را تغییر دهید.
  4. برای عوض کردن متن، «ویرایش متن» را بزنید.

چرا نمایش Markdown فارسی چالش دارد؟

بیشتر نمایشگرهای Markdown برای کل صفحه یک جهت ثابت چپ‌به‌راست در نظر می‌گیرند. در متن فارسی این یعنی پاراگراف‌ها چپ‌چین می‌شوند و بولت‌ها سمت اشتباه می‌افتند. وقتی فارسی و انگلیسی در یک جمله قاطی می‌شود، الگوریتم دوجهتی یونیکد ترتیب کلمه‌ها و علائم نگارشی را جابه‌جا می‌کند: نقطه‌ی پایان جمله به ابتدای آن می‌رود یا جمله‌ای که با نام یک فایل انگلیسی شروع می‌شود به‌هم می‌ریزد. کد و نمودارهای متنی هم وقتی کنار فارسی می‌آیند ناهم‌تراز می‌شوند. این ابزار برای حل همین مشکل‌ها ساخته شده است.

سؤالات متداول

چطور Markdown فارسی را آنلاین ببینم؟

متن را در کادر بالای همین صفحه paste کنید. بدون ثبت‌نام و نصب، همان‌جا به‌صورت راست‌چین و خوانا نمایش داده می‌شود.

آیا از متن ترکیبی فارسی و انگلیسی پشتیبانی می‌کند؟

بله. جهت هر بخش از روی زبان غالب آن تشخیص داده می‌شود و عبارت‌های انگلیسی داخل جمله‌ی فارسی، و برعکس، به‌هم نمی‌ریزند.

آیا برای استفاده باید نرم‌افزاری نصب کنم؟

خیر. ابزار یک صفحه‌ی وب است و در مرورگر اجرا می‌شود. برای بارگذاری فونت و کتابخانه‌های صفحه به اینترنت نیاز دارد.

آیا می‌توانم فایل .md را مستقیم باز کنم؟

بله. با دکمه‌ی «باز کردن فایل Markdown» یا کشیدن و رها کردن فایل (فرمت‌های .md، .markdown و .txt). فایل فقط در مرورگر خودتان خوانده می‌شود.

متن من به جایی ارسال یا ذخیره می‌شود؟

متن به هیچ سروری ارسال نمی‌شود. فقط آخرین متن و تنظیمات خواندن در حافظه‌ی مرورگر شما نگه داشته می‌شود تا با باز کردن دوباره‌ی صفحه از دست نرود؛ با دکمه‌ی «پاک کردن» حذف می‌شود.

آیا نمایش خروجی امن است؟

خروجی HTML پیش از نمایش با DOMPurify پاک‌سازی می‌شود تا کد مخرب موجود در متن اجرا نشود.

Persian & RTL Markdown Viewer

A browser-based Markdown viewer built for Persian (Farsi) and mixed Persian–English text. Paste Markdown or open a .md file and read it right-to-left: text direction is detected per paragraph, heading, list item and table cell, English phrases inside Persian sentences stay intact, and code blocks always stay left-to-right with syntax highlighting.

It runs entirely in your browser and your text is not sent to a server. It supports GitHub-flavoured Markdown (tables, task lists), a table of contents, box-drawing diagrams that contain Persian text, and reading settings for font size, line width, font and light, dark or sepia themes.
